# Kapani v29 — первое знакомство

При создании нового аккаунта после загрузки главной открывается обучение из пяти экранов. В нём кратко объясняются чаты и новости, банк и покупки, работа и услуги, остальные разделы сайта. Есть плавные переходы, кнопки «Дальше», «Назад», «Пропустить» и поддержка уменьшенной анимации.

Обучение запускается только для аккаунтов, созданных после обновления. При регистрации сохраняется маркер в профиле `settings.firstVisitTour`, после завершения или пропуска он помечается как выполненный. Локальный маркер нужен на случай кратковременной недоступности сохранения профиля. После обучения показывается отдельный запрос на включение уведомлений; системное разрешение спрашивается только после нажатия пользователем соответствующей кнопки. Для старых аккаунтов обучение не появляется.

Изменены `index.html`, `assets/kapani-main-classic.js`, `firebase-messaging-sw.js`; добавлены `assets/kapani-onboarding.js`, `assets/kapani-onboarding.css` и `tests/regressions-v29.cjs`. Для установки нужно перенести все файлы проекта вместе с обновлённым `index.html` и скриптами, сохранив пути. Отдельная SQL-миграция не нужна: используется разрешённое поле `settings` в существующем защищённом RPC `kp_profile_patch`.

Локальная проверка: `node tests/regressions-v29.cjs`. Проверены переключение экранов, возврат, пропуск и однократное завершение. Тесты других версий также должны проходить; браузерную проверку на реальном аккаунте после публикации стоит провести отдельно.
