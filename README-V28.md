# Обновление Капаней — ревизия 28 (7 ноября 2026)

Это частичное исправление выявленных проблем, а не полная переработка сайта по большому ТЗ. Подробный приватный отчёт приложен отдельно от папки проекта в ZIP-архиве.

В версии обновлены клиент накопительного счёта, PWA и Service Worker, добавлены PNG-иконки корректного размера, новая таблица стилей и тесты. Все прежние разделы и данные сохранены.

SQL `024_savings_ledger_account.sql` исправляет ограничение финансового журнала. SQL `028_savings_cron.sql` добавляет фоновое начисление накоплений, SQL `029_rls_and_foreign_key_indexes.sql` улучшает индексы и производительность политик доступа. Эти три изменения **уже применены** в базе действующего сайта. Повторно запускать весь `INSTALL.sql` нельзя. Для отдельной новой базы устанавливайте миграции в правильном порядке и только после резервной копии.

Чтобы опубликовать клиентские исправления, загрузите новые и изменённые файлы в существующий репозиторий без удаления остальных файлов. Версии подключённых ресурсов в `index.html` обновлены до 28. Вручную менять домен Supabase и секреты не нужно. Изменения клиента должны публиковаться одним согласованным коммитом.

Проверены серверные начисления, RLS-отказы, SQL-ограничения и статические тесты. Полный проход в авторизованном браузере и мобильная визуальная проверка ещё обязательны. Старый бакет публичных вложений и расчёт такси по прямой остаются незакрытыми архитектурными задачами.
