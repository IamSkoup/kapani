Капани, исправления 28 октября 2026, ревизия 18.

Этот архив содержит обновлённые HTML, JS, CSS и новую SQL-миграцию. Чтобы корзина доставки, уведомления доставщикам и очистка обращений бизнеса заработали, в Supabase откройте SQL Editor, нажмите New query, вставьте содержимое supabase/022_business_inbox_and_delivery_cart.sql и выполните Run. Это нужно сделать после миграций 001–021. Если в вашей базе пока нет 021, сначала выполните supabase/021_secure_quit_job.sql. Перед миграциями сохраните резервную копию данных.

Если база уже обновлена до 020 или 021, не запускайте старый INSTALL.sql повторно. Он предназначен для исходной установки дополнений 008–020. Новый SQL создаёт три защищённые функции для очистки обращений, оформления корзины и уведомления сотрудников доставки. Он не стирает истории заказов и не меняет существующие балансы сам по себе. Деньги за товары и доставку резервируются только при создании заказа пользователем на сайте.

После применения 022 загрузите все файлы новой версии на ваш GitHub Pages. Версии ресурсов в index.html уже изменены до 18. Для проверки откройте сайт с обновлением страницы без кэша. С двух отдельных тестовых аккаунтов оформите заказ с несколькими товарами и комментарием, убедитесь, что доставщик видит ровно одну карточку, получает уведомление, видит комментарий, может принять заказ, начать доставку, отметить её завершённой, а клиент подтвердить получение. Проверьте и заказ с маркетплейса, и заказ бизнеса, затем возврат при отмене до старта. После этого проверьте очистку обращений, кнопки корзины, покупку оформления, увольнение и мобильную верхнюю панель.

Уведомления внутри сайта теперь создаются защищённым сервером. Для системных push на отключённом телефоне по-прежнему требуется работающий push Worker и разрешение уведомлений в браузере. В среде подготовки нельзя было выполнить миграцию в вашем Supabase и проверить реальные устройства, поэтому результаты автоматических проверок не являются заявлением о прохождении полного живого теста.
